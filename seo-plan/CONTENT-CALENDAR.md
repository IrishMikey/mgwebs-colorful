Write these in Michael's own voice, with specific, checkable claims — generic AI-sounding advice here would directly undermine the pitch.

1. **"Why I still build sites by hand in 2026"** — the flagship positioning post. State plainly what "AI slop" looks like (identical layouts, same 3 fonts, generic stock-photo hero sections) and what's different about a hand-built site, using MGWebs' own portfolio as the proof.

3. **"What a holiday-rental site actually needs that template builders don't give you"** — ties directly to the Casa Magic/Villa Chloé case studies, strong long-tail SEO target for Tenerife rental owners specifically (served in English).

**Cadence:** 1 post/month starting Phase 2.

## Content guardrails (non-negotiable given the positioning)

- No AI-generated-sounding filler, no generic "in today's digital landscape" openers — every post should name a real project, a real constraint, or a real opinion.
- Every case study must include at least one specific, non-generic detail per project (a real technical decision, a real constraint, a real client quote if possible) — this is what makes the "not AI slop" claim credible rather than ironic.
- Keep post lengths honest to what's actually worth saying — a 1,500-word post stretched from a 400-word idea reads exactly like the AI-slop pattern being criticized.
